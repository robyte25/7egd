Willkommmen auf der Github - Seite von Geometry Dash Scratch Edition!
Vielen Dank für das Nutzen, Herunterladen und Spielen meines Spiels, ich hoffe es macht euch Spass!
Die Spielewebsite könnt ihr auf 7egd.pages.dev abrufen.
Dort kann man auch das Spiel im Browser spielen oder eine Android APK herunterladen.
SPIELANLEITUNG:

    Intro-Anleitung skippen mit Leertaste
    Springen mit Leertaste
    Münzen sammeln
    Geistern ausweichen
    Spitzen ausweichen
    Ausweichen bringt Punkte
    Auf blaue Balken springen (bringt Punkte)
    Auf Treppen steigen mit W-Taste

  Nach einiger Zeit werden Level aufgestiegen. Je nach Level wird das Spiel schneller.

  Wenn du Glück hast und lange genug spielst, erscheint eine Münze, die dich heilt!
